# Where my rules live

Portable behavioural rules ship in the `my-claude` plugin's `rules/`. To change one, edit it in the plugin repo and re-run `/my-claude:set-up`. Editing `~/.claude/rules/my-claude/` directly is pointless, the next sync replaces that directory.

Notes true only of one machine go in that machine's `~/.claude/CLAUDE.md`, which the sync never touches.
