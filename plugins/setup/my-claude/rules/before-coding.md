# Before coding

- Minimum code that solves the problem. If 200 lines could be 50, rewrite it.
- No abstractions for single-use code, no error handling for impossible cases.
- State assumptions when making a judgment call; ask only when readings diverge materially.
- If a simpler approach exists, say so, and push back when warranted.
